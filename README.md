# hackathon_max_2026

## Мини-приложение с картинками

Положите минимум два файла `.jpg`, `.jpeg`, `.png`, `.webp` или `.gif` в
`backend/temp/`. При нажатии на экран интерфейс запрашивает следующую картинку
и после последней возвращается к первой. В Docker-образ попадает набор файлов,
существующий во время сборки.

Запуск одним контейнером:

```sh
docker compose up --build
```

После запуска интерфейс и проверка состояния доступны по адресам
`http://localhost:8000/` и `http://localhost:8000/service/health`.
Порт задаётся переменной `PORT` в `.env` и по умолчанию равен `8000`.

Для разработки без Docker запустите процессы в двух терминалах:

```sh
cd backend && python -m src
cd miniapp && npm install && npm run dev
```

## Установка зависимостей

Python 3.12, активированное виртуальное окружение. Команды из корня репозитория.

Бэкенд:

```sh
python -m pip install -r backend/requirements.txt
```

Инструменты кодогенерации:

```sh
python -m pip install -r backend/tools/codegen/requirements.txt
```

[Структура и запуск](backend/docs/README.md) · [Кодогенерация](backend/docs/codegen.md)

## Git-хуки

Один раз для локального клона подключите общие хуки репозитория:

```sh
git config core.hooksPath .githooks
```

Перед коммитом выполняется `python -m tools.codegen --check`: проверяются
контракты и актуальность сгенерированных файлов. Перед отправкой изменений
в удалённый репозиторий запускается полный набор тестов бэкенда.
Хуки используют активированное виртуальное окружение или `.venv` в корне
репозитория.
